# Changelog

## Unreleased

- `MST0630-208-550-2x115_86149` is a standalone symbol in `Transformer-Murrelektronik`. The one-variant family base `MST_208-550_2x115` is removed. The part keeps the same drawing, pins, terminal rows, and part properties. Add lint rule `single-variant-base`: a symbol extended by exactly one other symbol in the same file is an error unless that symbol is a generic placed on the sheet. The message is that base symbols need 2+ variants and should be flattened. Existing hits in other libraries are in the baseline. `extends-parent` requires a named parent to exist in the same file. A single orderable part does not name a parent.
- `winding-gap` now scales with the number of winding sections in the symbol: at most 5.08 mm between windings when there are three or more sections, at most 10.16 mm when there are two. The two-winding current transformers keep their 10.16 mm spacing on purpose and no longer carry a `ki_winding_gap` exception.
- Move PE on `Control Transformer 1P` and `MST_208-550_2x115` into the primary terminal row, one grid step after pin 8 and pointing the same way. The dashed shield line runs under the primary and turns up into PE. The width stays 40.64 mm.
- Add lint rule `terminal-row`. A symbol that declares `ki_terminal_rows` (strips of pin numbers in strip order, separated by `;`) fails when a listed pin is missing, off its row, facing another way, or out of order. Both control transformers declare `1 2 3 4 5 6 7 8 PE; 9 10 11 12`.
- Move the Murrelektronik 630 VA control transformer out of `Transformer-IEC` into a new `symbol/Transformer-Murrelektronik.kicad_sym`. The part is `MST0630-208-550-2x115_86149`, named from Murrelektronik's designation `MST 0630-208...550/2x115` and order number 86149. It extends the family base `MST_208-550_2x115` in the same file. `Datasheet` is Murrelektronik's Product-PDF for 86149, which carries the terminal diagram and connection table.
- Redraw `Control Transformer 1P` and the Murrelektronik base to the Murrelektronik terminal diagram. The primary sections 1-3 and 4-8 and the two secondaries are one grid step apart instead of two, so the body is 40.64 mm wide instead of 50.8 mm. The secondary windings 9-11 and 10-12 cross their inner leads so the pins read 9, 10, 11, 12, as on the terminal strip.
- Add lint rules `generic-lib-manufacturer` (an `MFG` or `MPN` in a `*-IEC` library), `datasheet-document` (a datasheet that is not a `.pdf` or an approved download URL), and `winding-gap` (windings on one baseline too far apart, unless `ki_winding_gap` gives a reason), with tests. The 18 existing non-document datasheet links are added to the baseline. `Transformer-Murrelektronik` is not grandfathered.
- Add agent rules to `AGENTS.md` and the guidelines: where manufacturer parts live, how they are named, direct datasheet links, drawing to the manufacturer terminal diagram including crossovers, and one grid step between sections.
- Redraw `Transformer-IEC` at the house curl. The winding radius is 0.635 mm, the same curl as the AC coil and the contactor coil. Mapping the Radica 20-unit terminal pitch onto the 5.08 mm grid produces that radius. Bodies that were about twice the contactor are now the same height as `Contactor_3P_AC`.
  `AutoTransformer 1P` follows the Radica path: a straight 1N/2N trunk, a straight 1L leg, and low humps between them, with 2L leaving from between the humps. The tap is halfway across the winding, so the winding is two grid steps wide and has eight curls. The current transformer uses four curls so the C meets leads one grid step apart.
- Add `docs/symbol-guidelines.md` with the measured house dimensions, the scale-and-draw process, and the required side-by-side render. A body-size budget is not linted.
- `arc-radius` checks a winding curl only: two or more equal semicircles whose ends meet on a straight line. The default radius is 0.635 mm. 0.508 mm is also approved, for the tight curl measured on cable pigtail tails. Another size needs a `ki_winding_curl` property with a reason. The 105 baseline lines from the earlier every-arc check are removed.
- Add `symbol/Transformer-IEC.kicad_sym`.
  Generic symbols, drawn to the Radica IEC figures: Transformer 1P, Transformer 3P, Transformer 3P Bank, AutoTransformer 1P, AutoTransformer 1P Voltage Regulation, AutoTransformer 3P, Current Transformer, Current Transformer 1 Core 2 Windings, Current Transformer 2 Cores 2 Windings.
  Reference prefix is `T` for every symbol, including current transformers. That is the IEC 81346-2 class letter for transformers. Radica labels the same symbols `T1`.
  `Control Transformer 1P` is a single-phase multi-tap control transformer with two secondary windings and an electrostatic shield. Radica's IEC page has a multi-tap transformer, a screened transformer, and a three-winding transformer, and none of those is this part.
  86149 terminals, from the Murrelektronik product PDF (screw terminals 1–8 input, 9–12 output, PE) and the AutomationDirect multi-voltage connection table: primary pins 1–8, secondary pins 9–12, shield pin `PE`. For 400 VAC connect 1 and 6 and jumper 2–4. For 115 VAC connect 9 and 12 and jumper 9–10 and 11–12.
  The primary is two windings, not one chain. Section A is 1 (end), 2 (tap), 3 (end). Section B is 4 (end), 5, 6, 7 (taps), 8 (end). The humps stop between 3 and 4. That is the internal diagram on the AutomationDirect wiring page.
  The secondaries are coils 9–11 and 10–12. Jumper 9+10 with 11+12 then parallels them for 115 V, and jumper 10+11 puts them in series for 230 V.
- `Transformer 3P` is one joined row on each side. Each coil's right leg is the next phase's pin leg, and the last coil closes with an unlabeled return. There is no gap between phases.
- Add `tools/kicad_sym_lint.py`, run from pre-commit and CI. Existing violations are grandfathered in `tools/kicad-sym-lint-baseline.txt`. The new transformer library is not.
